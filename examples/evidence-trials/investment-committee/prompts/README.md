# Seat prompts

For each seat, make one initial user message by placing [`common.md`](common.md)
first and the seat's private file immediately after it. Replace
`{{ACCOUNT_NAME}}`, `{{ROOM_INVITE}}`, and `{{SURFACE_SENTENCE}}`; make no
other changes. `{{ACCOUNT_NAME}}` is always the standing Claude account and
agent name.

The same assembled seat packet is reused in all three arms except for the named
invite and the one registered surface sentence. Each arm starts in a fresh
session. Do not send a second message during the live task.

The private seat files are principal instructions. Do not paste one seat's
file into another seat's session or into the shared room.
