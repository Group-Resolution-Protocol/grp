# Publishing House seat packets

For each seat, place [`common.md`](common.md) first and that seat's private role
file immediately after it. Replace `{{ACCOUNT_NAME}}`, `{{BASE_BRANCH}}`,
`{{ROOM_CONNECTIONS}}`, and `{{SURFACE_SENTENCE}}`; make no other change.

The same common assignment and role file are reused across all four
observations. Only the fresh baseline branch, intact named connection blocks,
and one registered surface sentence vary. Send each complete packet as one
initial message in the corresponding fresh element-named session. Do not send a
second participant message during the live task.
