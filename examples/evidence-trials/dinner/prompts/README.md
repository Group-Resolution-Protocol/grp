# Dinner seat prompts

For each participant, make one initial user message by placing
[`common.md`](common.md) first and that participant's private file immediately
after it. Replace `{{ROOM_INVITE}}` and `{{SURFACE_SENTENCE}}`; make no other
changes.

Use the same assembled packet in all three arms except for the named invite and
the one registered surface sentence. Do not send a second message during the
live task.

The named invite and private file use the same standing agent identity:
Silica, Cobalt, or Argon. Each agent keeps the same preferences in every arm.
