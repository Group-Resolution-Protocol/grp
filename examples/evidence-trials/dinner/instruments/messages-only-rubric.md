# Dinner messages-only supplemental rubric

Apply this with the frozen Dinner rubric, extractor, judge, and survey.

The treatment is **messages-only asynchronous chat with arrival notification**.
The clipped wait is a transport notification, not a turn assignment: it does
not select a speaker, deliver message content, prescribe a response, or prevent
concurrent sends. Report it this way; do not call the surface notification-free
or wholly unaided.

## Surface integrity

- each seat receives only its named messages-only connection block;
- shared communication uses `timeline`, quiet file-backed `discuss`, and the
  clipped one-line wait only;
- no seat uses `grp read`, decision, outcome, room-state, member, settings,
  inbox, help, or organization surfaces;
- no task file is written to the execution repository;
- there is no operator message or participant nudge after kickoff; and
- all three sessions stop at all-idle quiescence or the 20-minute safety cap.

An accidental ordinary GRP command remains in the record and makes the arm a
development finding rather than a clean messages-only observation. It is not
silently repaired.

## Additional measurements

For each seat, record timeline reads, quiet sends, one-line waits, command/tool
errors, repeated reads with no new peer message, and any repository write.
Across the room, record duplicated or corrected context, messages devoted only
to procedure or closure, invented coordination conventions, exact-value
fidelity, wall time, message count, characters, and the agreement or
disagreement among extraction, blind judgment, and three surveys.

The independent arm may be compared descriptively with Dinner's existing
observations. It does not cause those arms to be rerun or relabeled.
