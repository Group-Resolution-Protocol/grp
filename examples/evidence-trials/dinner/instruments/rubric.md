# Frozen Dinner analysis rubric

Record setup integrity, all operator messages after kickoff, outcome
extractability, participant count, shared closure, exact survey agreement,
quorum illusion, wall time, room messages, available tokens/tool calls, and
standalone receipt verification for the treatment.

Catalogue any chair, tally, round, explicit assent check, deadline, ballot, or
final marker invented in chat. These are observations, not automatic failures.

Dinner is evidence against unnecessary structure if chat reaches one
mechanically extractable plan, all three participate, all three tool-free
surveys match, no coordination convention is invented, and chat uses less
time and fewer available cost units than the treatment. Report each condition
separately.
