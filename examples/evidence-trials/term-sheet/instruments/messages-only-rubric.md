# Term Sheet messages-only supplemental rubric

Apply this with the frozen Term Sheet rubric, extractor, judge, and survey.

The treatment is **messages-only asynchronous chat with arrival notification**.
The clipped wait does not select a speaker, deliver message content, prescribe
a response, or prevent concurrent sends. Do not call the surface
notification-free or wholly unaided.

## Surface integrity

- each seat receives only its named messages-only connection block;
- shared communication uses `timeline`, quiet file-backed `discuss`, and the
  clipped one-line wait only;
- no seat uses `grp read`, decision, outcome, room-state, member, settings,
  inbox, help, or organization surfaces;
- no task note or artifact is written to the execution repository;
- Argon remains a silent observer;
- there is no operator message or participant nudge after kickoff; and
- all three sessions stop at all-idle quiescence or the 60-minute safety cap.

An accidental ordinary GRP command or execution-repository write remains in
the record and makes the arm a development finding rather than a clean
messages-only observation. It is not silently repaired.

## Additional measurements

For each seat, record timeline reads, quiet sends, one-line waits,
command/tool errors, repeated reads with no new peer message, and any
repository write. Across the room, record:

- duplicated or corrected context;
- messages devoted only to procedure, package versioning, or closure;
- invented chairs, turns, deadlines, assent rules, version labels, or final
  markers;
- whether both negotiators identify the same controlling package text;
- whether the silent observer recalls that same text;
- exact-value fidelity, wall time, message count, and characters; and
- agreement or disagreement among extraction, blind judgment, and surveys.

The independent arm may be compared descriptively with the scenario's other
observations. It does not cause those arms to be rerun or relabeled.
