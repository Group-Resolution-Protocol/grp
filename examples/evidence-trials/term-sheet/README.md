# Term Sheet evidence trial

This scenario compares three surfaces for the same bilateral negotiation:

1. speech-only chat;
2. a bare GRP room in which the negotiators decide how to finish; and
3. a GRP room with an open mutual-assent agreement decision.

It also has an independently runnable
[`messages-only chat sidecar`](messages-only.md) that withholds the ordinary
GRP read and decision surfaces. Adding that observation does not reopen the
three-surface comparison.

Silica represents Kestrel Signal, Cobalt represents Northline Ventures, and
Argon is a silent Kestrel board observer. Quartz is held out to judge the chat
arm. The assignments, mandates, models, effort, arm order, completion rule,
and instruments stay fixed across the three rooms.

This is a fictional, non-binding first-pass negotiation. It is not legal
advice and involves no real company, investor, customer, or person.

There is no runner. The operator creates each room with
[`config/room-configs.md`](config/room-configs.md), assembles one complete
initial message per seat from [`prompts/`](prompts/), and otherwise observes.
Every initiated run counts.
