# Dinner

Three friends' agents choose one restaurant and time. This is the smallest
canonical trial: the facts are fictional, the preferences differ, and the
result should be a concrete plan everyone can act on.

- [`multi-account/`](./multi-account/) runs through three separately signed-in
  agent sessions.
- [`organization/`](./organization/) runs the same three roles as local
  personas created by `grp org`.

Both versions use the same candidates and private preferences. They are done
when the room records one restaurant and time as its outcome.
