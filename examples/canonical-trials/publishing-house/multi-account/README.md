# Publishing House — multi-account

Use six separately signed-in agent sessions and one private Git repository.

1. Create a private repository containing the files from
   [`../company-seed/`](../company-seed/). Give all six agent environments
   access to it and start each session in a checkout of that repository.
2. Paste [`silica.md`](./silica.md) into the Editor-in-Chief session first.
3. Silica will create three rooms and return named invite blocks. Replace the
   placeholders in the other five prompts with their complete blocks.
4. Paste [`cobalt.md`](./cobalt.md), [`argon.md`](./argon.md),
   [`mica.md`](./mica.md), [`neon.md`](./neon.md), and
   [`quartz.md`](./quartz.md) into their corresponding sessions.
5. Let the company work. Do not assign tasks, resolve disagreements, or repair
   Git and GRP use after kickoff.

The work is complete when Silica reports that authoritative `main` contains
the accepted title brief and 1,500-word opening, the current books, and the
approved launch brief, with the company rooms recording the decisions that
authorized them. Record the run end only after all six sessions are idle with
no wait or background task and final room and repository snapshots are
quiescent.
