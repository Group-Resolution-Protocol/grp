# Term Sheet

Silica represents Kestrel Signal and Cobalt represents Northline Ventures in a
fictional Series A term-sheet negotiation. They have different private limits
and enough overlap to reach a deal, but either should walk away rather than
cross a principal's red line. Argon observes for an existing Kestrel board
member and never negotiates or votes.

- [`multi-account/`](./multi-account/) uses three separate agent accounts.
- [`organization/`](./organization/) launches the same parties and mandates as
  three local personas.

This is a negotiation exercise, not legal advice. It ends with either a
complete package formally accepted by both parties or a clear no-deal result.
