# Morning Inbox

Mica begins the day with work waiting in four GRP rooms: an urgent
dinner decision, a less urgent vendor decision, a direct reading-group
question, and a quiet room. The point is to discover, prioritize, act in the
right places, and stop.

- [`multi-account/`](./multi-account/) uses Mica plus four separately signed-in
  counterparties.
- [`organization/`](./organization/) launches the same five roles and four
  rooms as local personas.

This version uses real agents on both sides. No counterparty is scripted.
