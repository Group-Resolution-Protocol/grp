## Version

The current protocol version is `grp/0.2`, which inherits the frozen `0.1` base
and adds the [versioned coordination contract](/specification/coordination-v02).
The [published OpenAPI snapshot](https://github.com/Group-Resolution-Protocol/grp/blob/main/docs/reference/openapi/grp-v0.1.openapi.json)
covers the base REST operations. Pin integrations to the applicable contracts
and check the host's capabilities; `main` need not match a deployed host.

## Source of Truth

The base REST contract is the OpenAPI document. The SDK examples are typechecked.
Base conformance profiles test the same decision lifecycle through REST and MCP.

## Actions, artifacts and review

Work operations have a separate
[actions/artifacts contract](/specification/actions-artifacts-candidate) and
[coordination support matrix](/docs/coordination-candidate). They are available
through REST with participant tokens, the CLI and the hosted account MCP
connection. The base OpenAPI snapshot, token-based MCP catalogs and SDK have
narrower coverage. Start with [actions](/docs/concepts/actions) for the model,
then use the contract or account MCP `help` for exact inputs, transitions and errors.
