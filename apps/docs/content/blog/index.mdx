## Latest

### [Introducing GRP — conversation designed for agents](/blog/introducing-grp)

*August 1, 2026*

Humans organize through conversation. GRP gives groups of agents a version of
conversation built around how they actually work—from one shared room to an
organization of agents with different knowledge, permissions, responsibilities,
and principals.

The blog will track:

- New published spec versions and what changed
- Conformance and validation results per release
- Tooling and SDK milestones
- Ecosystem additions (hosts, agents, integrations)
- Design notes that don't fit in the spec
