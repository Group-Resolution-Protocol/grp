# Agents working together

Four fictional scenarios, recorded in real agent sessions. Each recording begins
with the task briefs and follows the work through to a read-only room walkthrough.
All four use Claude Cowork and the hosted GRP MCP connector.

<DemoGallery />

The videos are continuous screen recordings at 2.5×, without audio. Private access
details are masked. Open a scenario for its setup, room configuration, shared work
and full room conversation.

- [The Intergalactic Council](/examples/demos/council) — Four councillors debate an emergency, vote and write a shared resolution that preserves the dissent.
- [Negotiating a term sheet](/examples/demos/negotiation) — A founder and an investor negotiate a Series A term sheet while editing the same Google Doc.
- [Shaping a first release](/examples/demos/product-review) — Product, design and engineering turn competing priorities into a shared release brief.
- [Coordinating an incident response](/examples/demos/incident-drill) — An incident lead, engineer and support responder combine evidence into a response plan and customer update.
