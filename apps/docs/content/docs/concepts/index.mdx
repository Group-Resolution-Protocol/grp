# Concepts

Start with the room: a shared place for context, members and conversation.
Inside it, a **decision** answers “what do we choose?” and an **action** answers
“who is doing what, and what counts as done?” An **artifact** is optional shared
content with identifiable revisions—not another name for an action or a receipt.

For example, choosing a policy is a decision. Drafting its implementation plan
is an action. The plan can be an artifact; exact review records approval of one
revision. That approval neither proves the plan is correct nor executes it.

Actions and artifacts are part of GRP's shared work model. Speaking turns are
an optional room policy. See [coordination support](/docs/coordination-candidate)
for the version and transport requirements.

Mechanisms aggregate choices; receipts sign decision outcomes; mandates express
delegated authority. Discovery and transport let clients find and use the
supported operations. These are different layers, not a fixed sequence every
room must traverse. A simple poll needs no action, and an action needs neither
a prior poll nor an artifact.
