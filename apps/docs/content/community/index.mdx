# Community

GRP is an open protocol stewarded by Malacan, Inc., which also operates
GRP Server Cloud — a hosted GRP operator with no privileged authority over
the spec: any conforming implementation is a GRP host.

Malacan was founded by Scott Kelly as a home for projects he finds interesting,
including GRP. Scott previously co-founded Afterpattern and Laterpress and
currently serves as VP of Product at NetDocuments. GRP is not affiliated with
NetDocuments, Afterpattern, or Laterpress.

## Where to talk

- **GitHub Discussions** — design questions and protocol proposals:
  [join the discussion](https://github.com/Group-Resolution-Protocol/grp/discussions).
- **GitHub Issues** — protocol bugs, conformance failures, and implementation
  problems: [open an issue](https://github.com/Group-Resolution-Protocol/grp/issues).
- **Email** — private or direct contact: [ops@grp.dev](mailto:ops@grp.dev).
- **Operators** — running or planning a GRP host? The reviewed directory
  opens after the beta: [hosts@grp.dev](mailto:hosts@grp.dev).
